# SafeRoute Mobile

Flutter app planned for both parent and driver experiences.

The first version should use role-based entry after login:

- Parent mode: child trip status, live bus map, notifications.
- Driver mode: trip controls, route stops, stop children, boarding/drop marking, emergency alert.

Flutter tooling is installed on this machine, but the current sandbox cannot update the Homebrew Flutter cache without approval. The actual Flutter project scaffold should be generated after Flutter can run cleanly.
